# ShiftERP Homebrew Tap

**This repo should be public** so `brew install shifterp-llc/tap/shifterp` works over
HTTPS without GitHub auth. Binaries are hosted on ShiftStack dl.

```bash
brew install shifterp-llc/tap/shifterp
# or:
brew tap shifterp-llc/tap
brew install shifterp
```

If the tap is still private (org default), tap via SSH once, then install:

```bash
brew tap shifterp-llc/tap git@github.com:shifterp-llc/homebrew-tap.git
brew install shifterp
```

`Formula/shifterp.rb` is regenerated by `make release VERSION=vX.Y.Z` in
[shifterp-cli](https://github.com/shifterp-llc/shifterp-cli) — binaries are hosted
on ShiftStack storage (`https://shiftstack.ai/dl/shifterp/...`). Don't edit the
formula by hand.

## After install

```bash
# Admin API token (auth tenants/accounts + schedule-api feedback admin)
shifterp auth set-key '<ADMIN_API_TOKEN>'

# Wire MCP + shifterp-operator skill into Claude Code, Cursor, and Grok Build
# (same pattern as mmntum install / stk install)
shifterp install
# subset: shifterp install --only grok

shifterp status
shifterp tenant list
shifterp feedback list
```

Restart AI tool sessions after `shifterp install` so MCP picks up. Tools run as
your stored admin token via `shifterp mcp serve`.

Optional `~/.shifterp/config.json` fields:

| Key | Default |
|-----|---------|
| `auth_base` | `https://auth.shifterp.com` |
| `api_base` | `https://schedule-api.shifterp.com` |
